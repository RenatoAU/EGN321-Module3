# Git Commit Guide — Assignment 3.1

Use at least 5 meaningful commits. Example sequence:

1. `Add Module 3 lookup workbook analysis`
2. `Represent valve lookup tables in Python`
3. `Implement exact lookup and interpolation helper`
4. `Add supported-range checks and extrapolation refusal`
5. `Add exact and interpolation tests`
6. `Add boundary and refusal tests`
7. `Document table ranges and interpolation behavior`

Avoid: `update`, `changes`, `stuff`, `final`.
